# Codex 医学监查 P0 规则发布链验收

## 结论

本切片达到约定的独立验收边界，可以作为医学监查后续真实项目 LOOP 的发布链基线。

## 已确认的关键行为

1. 自动影子样本不再用规则自身首次输出自证为可信 PASS。
2. provisional inspection 未经医学经理确认时不能发布。
3. `confirm-shadow` 绑定冻结 `sample_set_id`，确认后才能形成可信回归证据。
4. 影子确认和正式发布是两个独立动作。
5. 逐记录适用模式冻结完整聚合身份，prepare 到 execute 的漂移会被拒绝。
6. daily run 不会跨 batch 回退复用最近运行。
7. confirmed/published 包刷新后可以沿生命周期谱系取回已确认样本证据。
8. 已采用规则不显示“待医学批准”或“需医学复核候选”。
9. 前端不要求医学经理输入工程身份字段。
10. 项目切换、陈旧修订、跨项目访问、身份缺失和身份漂移均失败关闭。
