## 0. 结论（先看这里）

## 2. 大文件体验（本轮重点 1）

### 2.1 导入

- 向导第一步只接受**文件夹**，不接受单独点一个 xlsx。真实 DM 交付经常是单文件。
- 手填「数据位置」这次可用（目录内 18MB xlsx）。
- **132.8 秒**里按钮文案从「开始导入」变成「正在导入…」，然后突然变成第 2 步结果。t+2.5s 采样：interesting 含「正在导入…」，`progress: []`，`has54: false`。
- **进度条数 = 0，取消按钮 = 0。**
- 「暂停整理」在导入阶段就出现，和导入/识别抢语义；没有「取消本次导入」。
- 「整理在后台进行时，可以离开页面」与后面「刷新丢失第 3 步裁决」矛盾。

### 2.2 54 表字段概览的信息密度

页面原句：`1 个文件 · 54 张数据表 · 180793 行数据`。

**没有分组、没有搜索框、没有筛选、没有「可疑角色」汇总。** 按钮列表里搜不到「搜索 / 筛选 / 分组」。全文「搜索=0、筛选=0、分组=0」。

54 张表按出现顺序全量平铺（中文名来自页面）：
