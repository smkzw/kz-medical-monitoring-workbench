#### 3. 核心发现清单摘要
1. **【critical / product_bug】向导第 3 步轮询漏传 `batch_id` 致 HTTP 422 与界面永久假死锁死**
   - 接口：`GET /api/projects/{id}/modules/medical-monitoring/r7/data-admissions/{stg_id}/study-documents/resolve` 缺少 `?batch_id=...`。
   - 现象：后端返回 `{"code": "mapping_resolve_batch_id_required", "message": "研究文件核对查询缺少批次参数（batch_id）。请返回向导重新进入第3步；若持续出现请刷新页面。"}`，前端完全隐藏错误提示，呈现无限等待，输入框置灰。
2. **【high / product_bug】后端服务偶发周期性超时（>20s），前端全屏置灰禁用“新建项目”及所有业务模块**
   - 现象：测试初期页面请求 `/api/projects` 超过 20 秒无响应，界面降级显示“项目服务暂不可用”，并将“新建项目”和所有子模块导航按钮属性设为 `disabled: true`，用户失去操作入口。
3. **【medium / ux_issue】向导状态缺乏路由/持久化，用户刷新页面后向导静默收起丢失上下文**
   - 现象：按系统建议刷新页面后，向导步骤关闭，回到未选择记录的主看板，需重新点击“开始数据接入”触发耗时恢复。
4. **【low / cosmetic】方案规则发布抽屉中文案排版折叠截断**
   - 现象：前置链说明文案末尾出现未展开的省略号截断（如“...角色确认 ...”）。
