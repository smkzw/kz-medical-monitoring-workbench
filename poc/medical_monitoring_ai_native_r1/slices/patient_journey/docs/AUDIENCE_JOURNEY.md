# 受众说明：受试者医学旅程（Slice 4）

## 这是什么

隔离 R1 切片中的**只读**受试者医学旅程工作面。面向医学监察员，用同一条时间脊把访视轴、事件泳道、指标趋势、风险与证据同步展示。

数据全部为合成演示数据，不代表真实受试者。

## 如何打开

用本机浏览器直接打开：

`poc/medical_monitoring_ai_native_r1/slices/patient_journey/index.html`

无需服务器。页面会相对加载：

- Slice 3 只读数据包 `../aemh_audience_workbench/data/mm_r1_data.js`
- 本切片旅程数据 `data/journey_fixture.js`

不要改动 Slice 3 文件。

## 四个同步视图

| 页签 | 作用 |
|---|---|
| 旅程总览 | 固定访视轴、阶段带、四条泳道、单日/持续记录、风险位置标记 |
| 指标趋势 | 按领域投影到同一时间窗（实验室、AE/症状、暴露、病史/用药/住院） |
| 事件明细 | 单日记录、持续记录以及日期信息不完整的记录 |
| 风险依据 | 当前风险、支持/排除依据、数据来源与 Query 草稿 |

页签、时间窗、坐标模式与选中项共享同一状态。

## 交互约定

- 默认受试者：`SYNTHETIC-SUBJECT-001`
- 顶栏显示受试者、中心、时间窗截止；不展示内部哈希或调试字段
- 点击或键盘激活（Enter / 空格）风险或事件：交叉高亮同一身份，并打开中文证据面板
- Escape 关闭证据面板，焦点回到打开前的控件
- 当前时间范围外的风险仍可在「风险依据」查看；不会因此改变风险状态
- 「优先显示中高风险」默认开启；日期信息不完整的记录进入独立区域，不强制放入时间轴

## 标记语义（不只靠颜色）

- 事件首先按临床域区分：AE、MH、CM/合并用药、IP给药、实验室/检查、住院/操作、症状/体征线索各有独立文字、颜色和形状。
- 持续事件的横条沿用相同临床域颜色；开放结束日期仅改变末端线型，不改变事件类别。
- 风险同样按 AE、MH、CM、IP给药、实验室/检查、住院/操作、症状/体征线索分域；菱形表示“风险”，菱形内缩写表示所属临床域，旁侧“高/中/低”表示风险等级。
- 症状/体征线索使用虚线，不能与已记录 AE 混为一种事件。

`formal_fact`、`candidate`、`established_risk` 等只允许存在于内部数据合同和测试中；受众界面必须转换为具体医学监查语言，禁止显示“正式事实”“候选信号”“已建立风险”等系统术语。

## 明确不做

- 不写回医学确认、风险处置或人工任务
- 不发起远程请求、不安装依赖、不启动服务
- 受众界面不暴露内部字段名、原始 JSON、日志或后端词汇
- 不修改 Slice 3、产品代码、医学写作服务或共享运行库

## 实现文件

- `index.html` — 外壳与页签
- `styles.css` — 浅色康哲视觉合同、内部横向滚动、可见焦点、减弱动效
- `app.js` — 共享状态、访视轴投影、证据面板
- `data/journey_fixture.js` / `docs/DATA_CONTRACT.md` — 由数据合同工人维护（本说明不修改）
