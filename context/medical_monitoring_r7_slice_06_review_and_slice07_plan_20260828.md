# R7 Slice-06 复盘与 Slice-07 阶段前计划

日期：2026-08-28  
状态：`R7_SLICE_07_PHASE_BEFORE_REVIEW`

## 1. Slice-06 已证明什么

R7 Run/work-unit 已可通过冻结 ExecutionProfile 进入真实 R6 OMP adapter，并把
原始 receipt、R1 attempt、R7 control 和公开中文进度保持为不同权威层。默认 MTPLX
medium 与显式 DeepSeek max 均已在 synthetic 单元上真实完成；300 秒 run override
为本地 MTPLX 提供了足够等待时间，且没有自动 fallback。

## 2. 尚未证明什么

尚未证明普通用户在产品页面上能直观看到真实分母、离页后台运行、停止/中断/继续
入口和稳定中文状态；也未验证刷新、窄宽屏、键盘可达、空态/失败态或项目/中心流向
看板。真实项目与医学内容质量仍不在本阶段。

## 3. 用户任务与界面原则

资深医学监察员应能在不理解模型与后端术语的前提下：开始监查后立即知道总项数、
已完成数和当前工作；离开页面后任务继续；返回后看到同一持久状态；中断时只看到
“已中断，可继续”；失败时得到可操作中文提示。页面不出现 provider、model、selector、
attempt、lease、hash、日志标签、“正式事实”“候选信号”或“只读”等研发词汇。

## 4. Slice-07 分步计划

1. 只读梳理现有产品路由、前端页面、R7 runtime-progress API 与 R5 已冻结视觉合同，
   冻结本切用户任务、状态、交互、宽屏/窄屏和无障碍验收矩阵。
2. 最小接线真实持久化进度：准备、开始、停止、继续、刷新/离页返回；数字只能来自
   manifest/work-unit 分母，不做定时假增长。
3. 用中文任务说明替代内部事件流；长日志不直接给用户，只滚动展示当前正在进行的
   医学工作与最近完成项。
4. 在隔离 synthetic workspace 启动受控产品端口，使用 ego(lite) 验收真实页面、离页
   后台、刷新恢复、失败态、停止态、无后端术语和视觉层级；验收后停止服务。
5. 独立视觉会商与 Codex 复核完成后，再进入 Slice-07B 项目/中心受试者流向看板：
   “知情同意→筛选→治疗→研究状态”动态阶段流、风险叠加与下方明细表双向对账。
6. Slice-07B 通过后，再进入 Subject Journey/共享访视轴的真实产品接线；不得把三个
   大界面同时铺开造成一次性重构。

## 5. 停止线

不运行五个真实项目，不修改医学写作，不把 synthetic UI 验收外推为医学质量或 R7
总体接受。本阶段不设计、实现或测试系统安全功能；模型凭据只复用现有不可见引用，
不在此切片增加管理界面。浏览器只使用 ego(lite)，不使用 Playwright。
