# 医学写作边界检查缓存排除纠偏（2026-08-28）

## 目的

医学监查 R7 的相邻边界测试原先把路径名含 `medical-writing` 或
`medical_writing` 的所有常规文件都计入摘要，其中包括 Python
`__pycache__`、pytest 缓存和 `.pyc`。这些文件是可再生运行缓存，数量和内容会随
解释器、测试顺序及缓存清理变化，不能作为“医学写作源码未被修改”的稳定证据。

## 纠偏

- 保留原有五个受保护根目录与路径匹配规则。
- 遍历时明确剪除 `__pycache__`、`.pytest_cache`，并忽略 `.pyc`。
- 当前源码及其他非缓存常规文件基线为 443 个，聚合 SHA-256 为
  `394746881c0b8b312805ee6e22047f6e32b66559d76987a7337ab151ed04a1c1`。
- 旧缓存相关基线 542 个、聚合 SHA-256
  `feef0f171e6c102e56c930de57afb2cfaf78e7bfacc33f17d1fa8cfb7cb3d1ca`
  仅说明当时缓存状态，不再用于源码边界验收。

## 边界与结果

本次只修改医学监查 R7 的边界测试口径，没有写入医学写作产品源码。缓存清理不再
制造虚假的相邻系统漂移；后续医学监查切片以非缓存文件的稳定聚合值保护并行开发
中的医学写作子系统。

## 验证

`test_background_recovery.py` 与纠偏后的医学写作聚合边界测试合计 15 项通过。
