# 字段映射语义质量门集成记录

## 目标

防止“字段数量完整但医学语义错误”的独立 AI 映射被确认或激活，同时避免把技术诊断
堆叠到医学经理主界面。

## 已实现

1. 纯函数评估器对完整字段集合生成确定性质量报告。
2. 正式确认前重新计算；存在全局或能力级阻断项时拒绝确认。
3. 正式版本固定报告正文与 SHA-256，版本 ID 同时纳入报告哈希。
4. 激活前重新计算并核对报告正文、哈希和当前映射；缺失或不一致均失败关闭。
5. 前端确认区仅呈现“可确认/需先修订”和归并后的医学问题组；不常驻技术日志。

## 首批医学边界

- 全字段覆盖与重复映射；
- 项目、中心、受试者、访视、表单和记录等技术元数据的一致语义；
- CM 仅表示非试验用药，试验药物给药及变更必须单列；
- 试验药物实际给药、剂量调整、暂时停药、永久停药、恢复给药、发放、回收和依从性
  不得混为同一角色；
- MedDRA 与药品编码需保留字典及版本血缘；
- 固定派生字段需保留来源字段、公式及用户确认血缘。

## 后续真实项目门禁

RUX 与 MG-K10 的 V11 独立 AI 映射完成后，必须先汇总为草稿并运行本质量门。发现的
阻断项优先修订通用提示词、角色目录或确定性规则；不得为单项目硬编码或直接修改运行库。
