# R7 Slice-08C-2 项目/中心连续性前端纵切合同

日期：2026-08-29  
状态：`FROZEN_FOR_IMPLEMENTATION_R7_SLICE_08C2`

## 1. 用户结果

资深医学监察员进入一个已发布结果的项目或中心看板时，无需理解 Run、digest 或 artifact，即可先看到本轮相对上轮的关键变化，再沿同一受试者和时间窗进入 Patient Journey 或来源。

## 2. 本切范围

1. 在现有 R7 public result API 增加 continuity GET 客户端；只传既有可选 `site_ref`。
2. 新增严格前端投影：精确字段闭集、九项计数重建、中文枚举、排序、截断与内部字段门；非法响应整块不展示。
3. 项目/中心结果页在既有看板之前显示：比较说明、五个关键计数、默认中高风险优先的变化列表、紧凑筛选和截断提示。
4. 风险行仅在能从当前 R5 结果投影补齐同一 `subject_ref + spine_ref + window_start + window_end` 时允许进入 Patient Journey；不得从内部引用拼造受试者或中心中文名称。
5. 来源入口仅在当前行具有可用的 `risk_instance_ref + source_locator_ref` 时启用，并继续复用现有公开来源路由。

## 3. 明确不做

- 不改变 Journey 时间轴几何、事件图标或风险节点；这些属于 08C-3。
- 不实现右侧详情抽屉、焦点锁定或 push/overlay；这些属于 08C-3。
- 不重做现有项目壳层、Sankey、中心表格或医学写作页面。
- 不新增前端依赖，不启动 8911/5174，不运行真实项目或模型。

## 4. 公开中文与信息层级

- 首屏标题使用“本轮变化”，副文案只表达“首次全面分析”或“已与上次监查结果比较”。
- 摘要顺序：新增、升级、重开、需重新判断、中高风险；不得限制为 3–5 项。
- 默认风险等级筛选为“中高风险”；用户可切换“全部、高、中、低”。
- 变化筛选为七类闭集，类别筛选为风险/Query 草稿/监查结果项，另提供“仅看需重新判断”和受试者搜索。
- Query 草稿与监查结果项不得伪造风险等级或受试者 Journey 入口。
- 页面不得显示内部 token、schema、hash、运行日志或“正式事实/候选信号/人工复核未完成”。

## 5. 失败与加载

- continuity 加载不阻塞既有结果看板；加载中显示短占位。
- `continuity_unavailable` 或前端校验失败时，只显示“本轮变化暂不可查看”，既有结果看板仍可查看。
- 切换项目、结果上下文或中心时取消旧请求并清空旧比较，禁止跨项目/跨中心闪回。

## 6. 验收

1. API 路径、query、signal 与错误合同测试。
2. 投影纯函数覆盖精确闭集、九项计数、排序、中文值、截断、内部字段与篡改失败关闭。
3. 组件渲染覆盖默认中高风险、全部/等级/变化/对象/受试者筛选、首次/增量、空态/错误态、Journey/来源按钮门。
4. R7 产品循环集成覆盖项目/中心切换、旧请求取消、continuity 不阻塞主体结果、同一身份路由。
5. 前端相邻测试、Vite build 与医学写作保护面不变。

08C-2 通过独立实现审阅前不得称为接受；浏览器三视口与专项视觉接受仍留在 08C-4。
